# Flora_Format.txt
# How to write a biome plant shortlist.
# How to read Domain, Biome, and HSI is in Bestiary_Rules.txt.
# Biome tags come from Geography_Rules.txt.

File name
Flora_[Biome].txt
Use the locked biome tag. Spaces become underscores.
Examples: Flora_Boreal.txt / Flora_Temperate.txt / Flora_Wetland.txt

# Flora_[Biome]
# Shortlist for this biome. Not an ecosystem.

Biome: [locked tag]

COVER
The plants that make the country look like this biome.

Omit a section if this biome has nothing for it.
Repeat the plant in every Flora_ file whose biome tag it carries.
Agriculture sits on working land, not on every matching feature.
A dash (—) on an HSI axis means indifferent.
Fauna on a plant line is animal life around the plant, not the plant’s own abundance.
