# Flora_Oceanic_Format.txt
# How to write a sea-climate plant shortlist.
# How to read Domain, Biome, and HSI is in Bestiary_Rules.txt.
# Biome and Place tags come from Geography_Rules.txt.
# Use oceanic HSI meanings. Do not use land meanings.

File name
Flora_[Sea-climate].txt
Locked names only:
Flora_Polar_sea.txt
Flora_Cold_sea.txt
Flora_Temperate_sea.txt
Flora_Warm_sea.txt
Flora_Tropical_sea.txt

Do not make Flora_Strand.txt the master list.
Do not use the land tag Oceanic as a sea-climate.

# Flora_[Sea-climate]
# Shortlist for this sea-climate. Not an ecosystem.

Biome: [Polar sea / Cold sea / Temperate sea / Warm sea / Tropical sea]

STRAND
SHELF
GULF
OPEN SEA
ABYSSAL

Omit a section if this climate has nothing for it.
List a plant once in this file. If it uses two Places, put it under the shallower Place and name both on the Place line.

[Name]
Domain: Marine
Biome: [this sea-climate and any others it belongs to]
Place: [Strand / Shelf / Gulf / Open sea / Abyssal]
HSI: Temperature: X–Y | Rainfall: X–Y | Human Density: X–Y | Flora: X–Y | Fauna: X–Y | Topography: X–Y | Hydrology: X–Y
Rarity: X
Use: [weed, kelp, wrack, dye, food, reef] | Notes: [ ]

HSI is oceanic. Topography is depth. Hydrology is sea-state.
Fauna on a plant line is animal life around the plant, not the plant’s own abundance.
A dash (—) means indifferent.

COVER / FORAGE / HAZARD may be used as a second label on the Notes line.
Do not put land crops here. Sown take is Economy_Agriculture.txt.

PLACEMENT
1. Domain
2. Open the file whose sea-climate matches the region Biome or a Sub-biome
3. Keep lines whose Place hits the region Biome or a Sub-biome
4. Then HSI against the region or the matching feature

Repeat the plant in every sea-climate file whose tag it carries.
Open sea and Abyssal flora will be thin. That is correct.
