# Roleplay AI Loader File
# Always read this document first
# Repo: https://github.com/flyingsmartie315-crypto/Homebrew-RPG
# Indexed against main (115 blobs). Update this file when the tree changes.

This is the mandatory starting point for every session and every query.
Before loading any other file or generating a response, the AI must consult
this Loader File to determine which repository documents are required.

=== EXTERNAL STORAGE & AUTO-INFERENCE PROTOCOL ===

All files live on the public GitHub repository:
https://github.com/flyingsmartie315-crypto/Homebrew-RPG

Raw URL (spaces as %20):
https://raw.githubusercontent.com/flyingsmartie315-crypto/Homebrew-RPG/main/[path]

Example:
https://raw.githubusercontent.com/flyingsmartie315-crypto/Homebrew-RPG/main/Master/Core/Armour.txt
https://raw.githubusercontent.com/flyingsmartie315-crypto/Homebrew-RPG/main/Master/Economy/Finished%20Goods/Economy_Finished_Armour.txt

Auto-Inference Rule:
Detect which files are needed from plain-language queries. The user does
not need to name files. Fetch full exact text with browse_page on the raw
link. Load only what the current query needs. Chain if the scene widens.

=== CORE RULES REFERENCE PROTOCOL ===

Mechanics first when the query is rules, dice, characters, combat, injury,
armour, weapons, shields, size, encumbrance, time, or company play.

Load order for a swing:
  Core_Resolution.txt
  Core_Characteristics_Skills.txt
  Core_Combat.txt
  Weaponry.txt and/or Shield_Rules.txt
  Armour_Rules.txt then Armour.txt
  Core_Injury.txt then the Entity's Injury Table file

The Entity sheet names the injury table:
  Injury Table: Injury_Tables_X.txt
Missing line defaults to Bipedal. Do not guess from Size.

RULES FOR FILE ACCESS AND INFERENCE:
1. You may reference any file in the index without the user naming it.
2. When the player mentions a person, place, faction, creature, event,
   or concept, check the matching files.
3. Infer and cross-reference.
4. When in doubt, use this index, then pull the fewest files that answer.
5. Do not contradict loaded lore. Campaign_Log.txt wins on world state.
6. New content stays grim, grounded, low-to-mid supernatural horror.

=== REVISION & CONSISTENCY PROTOCOL ===

Revising a document: load the original, then supporting files. Merge.
Preserve tone, names, and lore unless the user asks for a rewrite.

=== FALLBACK & MISSING FILES ===

If a file is not in the index or will not fetch:
- Say it is missing.
- Use Core_RP_Guidelines.txt, already-loaded files, and tone.
- Do not invent major lore or rules that would fight a future official file.
- Offer to draft the missing file.

=== PURPOSE ===

Parse the query. Match it to the index. Load what is needed. Do not load
the whole repository.

--------------------------------------------------
CORE  (mechanics — this chat's law)
--------------------------------------------------

Core_RP_Guidelines.txt
  Tone, agency, dice transparency, immersion. Wins on dramatic call.

Core_Resolution.txt
  d100, success/fail, DoS/DoF, opposed tests, bonuses, narrative vs
  structured time, keywords (Entity).

Core_Characteristics_Skills.txt
  Characteristics, bonuses, skills (known / *advanced), Size, Movement,
  Enc bands (S×5 unencumbered, S×10 combat load), Wounds, NAC, Initiative,
  Attacks, IP, FP, lift/press/push.

Core_Combat.txt
  Rounds (10 seconds), initiative (Ag+1d10, reroll each round),
  action economy, basic actions, movement yards, Called Shot,
  opposed Dodge/Parry, hit procedure, prose format.

Core_Injury.txt
  When injury happens. 2d100: Wallace then Slot. Points at the table
  file named on the Entity sheet. Bleed, Overflow, Fate.

Injury_Tables_Bipedal.txt
  Man-shaped. Head, torso (incl. Armpit), arms, legs.

Injury_Tables_Equine.txt
  Horse-type. One toe. No muscle below knee/hock.

Injury_Tables_Predator.txt
  Paws: wolf, hound, great cat, gryphon.

Injury_Tables_Hoofed.txt
  Cloven / pig hoof: elk, bison, cattle, pig, sheep, goat.
  Not horse.

Injury_Tables_Spider.txt
  Eight legs. Cephalothorax and abdomen. Pedicel 8 is two pieces.

Armour_Rules.txt
  Layers, Slots, Coverage, soak cascade, Enc, Forms, Iron Grade,
  Natural Armour, pairing / bulk / closed helm.

Armour.txt
  Catalogue. Models, Forms, AC, Enc, Common cost (mid of
  Economy_Finished_Armour). Iron Grade shared with Weaponry.

Weaponry.txt
  Profiles Cut/Pierce/Blunt, Reach, Range, qualities, craft,
  Iron Grade, ammunition, siege as narrative.

Shield_Rules.txt
  Held, not slotted. Defensive(x), free Parry including shot,
  overflow through the shield AC onto the wearer.

QUERY ROUTING (short)
==================================================

Dice, tests, time                 Core_Resolution
Stats, skills, size, Enc, wounds  Core_Characteristics_Skills
A fight                           Core_Combat + Weaponry + Shield_Rules
A hit landing                     Armour_Rules + Armour + Core_Injury
  + the named Injury_Tables_*
Kit price / who can make it       Economy_Finished_Armour + Labour
  + Processed_Goods + Processing_Matrix
A creature on screen              Bestiary_* + Bestiary_Rules
  + matching Injury table
A place                           Geography_Rules + that region
  + settlements + Customs if Kannavald
What year / season it is          World_Calander + Campaign_Log
Tone fight                        Core_RP_Guidelines

Do not load Economy when the query is only a swing.
Do not load every bestiary when the query is one beast.
