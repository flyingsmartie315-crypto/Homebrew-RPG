# Roleplay AI Loader File
# Always read this document first
# Repo: https://github.com/flyingsmartie315-crypto/Homebrew-RPG
# Indexed against main (239 blobs). Each entry has a contents summary for auto-inference.
# Index refreshed: 2026-11-22

This is the mandatory starting point for every session and every query.
Before loading any other file, consult this index.
Match the query to the summaries. Load only the files the query needs.

Raw URL (spaces as %20):
https://raw.githubusercontent.com/flyingsmartie315-crypto/Homebrew-RPG/main/[path]

Auto-Inference Rule:
Read the summary, not just the filename.
A query about a fight loads Core_Combat, Weaponry, and the injury table named on the sheet.
A query about a place loads that region and its settlements.
A query about a beast loads its Bestiary entry and its Entity block.
A query about a person, or an NPC interaction or generation, loads Format_NPC_Profile and, to generate an NPC,
NPC_Generation_Protocol, Core_Characteristics_Skills, Core_EXP, Core_Talents_Failings_Afflictions, Economy_Labour
(occupation and wage band), the Peoples file for the NPC's culture, the settlement or
Local Region where the scene sits, World_Calendar and Campaign_Log (date and season),
and the NPC's own _NPC_Profile.txt if one exists.
A query about coin loads Economy_Rules and the relevant primary, processed, or finished file.
Do not load the whole repository.
